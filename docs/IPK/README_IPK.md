# IPK Docs Navigation

This file routes future Codex sessions inside `docs/IPK/`.

## Read First

- Read `ipk-docs-readme.md` for the broad doc-set overview.
- Read `01-ipk-content-system/` when the task concerns content ingestion, structuring, search, or retrieval.
- Read `02-user-adaptation-system/` when the task concerns adaptation, memory, user modeling, or response shaping.
- Read `reference_project_review/` when the task is comparative or borrows ideas from outside systems.

## Directory Guide

| Name | What It Holds | When to Read |
|---|---|---|
| `01-ipk-content-system/` | Content-side architecture and implementation notes. | Read for IPK content flow, storage, and retrieval tasks. |
| `02-user-adaptation-system/` | User adaptation and memory-boundary material. | Read for user-state, adaptation, or bounded-memory tasks. |
| `reference_project_review/` | Structured analysis of reference systems and imported ideas. | Read when comparing with external designs or migration candidates. |
| `legacy/` | Older IPK material retained for history. | Read only when newer docs point back here or when tracing prior decisions. |
